PASSWORD RESET — fix "cannot reach the page"
=============================================

The email link fails when Supabase sends you to localhost or a URL that is not running.


FASTEST FIX (no email link needed)
----------------------------------
1. Supabase → Authentication → Users
2. Click k12strategies@perkinseastman.com
3. "Reset password" → set a new password → Save
4. Sign in on admin.html


FIX EMAIL RESET LINKS
---------------------

A) Serve the site over http (not by double-clicking HTML files)

   In this folder, run:
     npx serve .

   Open: http://localhost:3000/admin.html
   (Port may be 3000 or 5500 — use whatever the terminal shows)


B) Supabase → Authentication → URL Configuration  ← REQUIRED for email links

   See SETUP-AUTH-URLS.txt. Site URL must be:
     https://pe-k12-strategies.github.io/SchoolExplorer
   (not http://localhost:3000)


C) js/config.js

   window.APP_BASE_URL = 'https://pe-k12-strategies.github.io/SchoolExplorer';


D) Use Forgot password on admin.html or index.html

   Opens reset-password.html after you click the email link.
