AUTH EMAILS — permanent fix (hosted confirm links)
==================================================

Problem: Supabase Site URL / Email Templates are locked, so built-in confirm
emails still open http://localhost:3000.

Fix: signup + password reset go through Edge Function `auth-email`, which
emails a GitHub Pages link:

  https://pe-k12-strategies.github.io/SchoolExplorer/auth-confirm.html?token_hash=…&type=signup


ONE-TIME SETUP (Supabase Dashboard)
-----------------------------------

1) Deploy the function
   Edge Functions → Create / Deploy function named: auth-email
   Paste code from: supabase/functions/auth-email/index.ts
   Important: disable JWT verification for this function
   (or deploy with: supabase functions deploy auth-email --no-verify-jwt)

2) Function secrets (Project Settings → Edge Functions → Secrets, or function Secrets)
   SUPABASE_SERVICE_ROLE_KEY  = Project Settings → API → service_role (secret)
   RESEND_API_KEY             = same key used by notify-admin-signup (if any)
   FROM_EMAIL                 = PE Dashboards <onboarding@resend.dev>   (or your verified sender)
   APP_BASE_URL               = https://pe-k12-strategies.github.io/SchoolExplorer

3) Test
   Sign up a new test address on:
     https://pe-k12-strategies.github.io/SchoolExplorer/
   Confirm email should open auth-confirm.html on GitHub Pages (not localhost).
   Then approve the user on admin.html as usual.


If RESEND_API_KEY is missing
----------------------------
Signup will fail with a clear error until the secret is set. Reuse the Resend
key already configured for notify-admin-signup when possible.


Manual rescue (still works)
---------------------------
sql/confirm-user-email.sql in the SQL Editor, then approve on admin.html.


Old workarounds (only if you gain Owner access later)
-----------------------------------------------------
• Site URL → https://pe-k12-strategies.github.io/SchoolExplorer
• Or custom Confirm signup template using TokenHash (see git history)
