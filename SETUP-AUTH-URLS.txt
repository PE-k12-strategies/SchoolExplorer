AUTH EMAIL LINKS — Confirm signup template (preferred)
======================================================

You do NOT need the auth-email Edge Function if you can edit Email Templates.


1) Redirect URLs
----------------
Authentication → URL Configuration → Redirect URLs — add:

  https://pe-k12-strategies.github.io/SchoolExplorer/**
  https://pe-k12-strategies.github.io/SchoolExplorer/auth-confirm.html
  https://pe-k12-strategies.github.io/SchoolExplorer/index.html
  https://pe-k12-strategies.github.io/SchoolExplorer/reset-password.html

If you can also edit Site URL, set it to:
  https://pe-k12-strategies.github.io/SchoolExplorer


2) Confirm signup template (required)
-------------------------------------
Authentication → Email Templates → Confirm signup

Replace the body with:

  <h2>Confirm your email</h2>
  <p>Confirm your School Explorer account:</p>
  <p>
    <a href="https://pe-k12-strategies.github.io/SchoolExplorer/auth-confirm.html?token_hash={{ .TokenHash }}&type=signup">
      Confirm email address
    </a>
  </p>

Do NOT use {{ .ConfirmationURL }} or {{ .SiteURL }} (those still go to localhost).

Save.


3) Reset password template (recommended)
----------------------------------------
Authentication → Email Templates → Reset password

  <h2>Reset your password</h2>
  <p>
    <a href="https://pe-k12-strategies.github.io/SchoolExplorer/auth-confirm.html?token_hash={{ .TokenHash }}&type=recovery">
      Reset password
    </a>
  </p>


4) Test
-------
Sign up a new address on:
  https://pe-k12-strategies.github.io/SchoolExplorer/

The email link should open auth-confirm.html on GitHub Pages.


Manual rescue
-------------
sql/confirm-user-email.sql — then approve on admin.html.


Optional fallback
-----------------
supabase/functions/auth-email/ — only if templates become locked again.
